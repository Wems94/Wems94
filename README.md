## ▸ About

Analytics & Data Engineer with **4 years** building end-to-end data solutions for high-volume B2C products — from raw ingestion to governed, self-service analytics that teams actually use to make decisions.

**Currently**
- 💼 Open to **Analytics Engineer / Data Engineer** opportunities
- 🏗️ Focused on **lakehouse architecture, data modeling and semantic layers**
- 🛡️ Advocating **data quality, governance and documentation** as part of the product

## ▸ What I Do

**⚙️ Data Engineering**
- Design **lakehouse pipelines** in a medallion architecture (bronze → silver → gold) with PySpark and dbt
- Build **ETL/ELT and API ingestion** orchestrated with Airflow and Databricks Workflows
- Ship data with **CI/CD and automated quality tests**, so pipelines stay reliable at scale
- Structure data domains on **BigQuery and Snowflake** following **Data Mesh** principles

**📊 Analytics Engineering**
- Model data into **semantic layers and single sources of truth** for business KPIs
- Standardize **metric and dimension definitions** so every team reads the same numbers
- Deliver **self-service dashboards** in Tableau, Power BI and Looker, built on reusable templates
- Turn data into decisions with **statistical analysis, clustering (K-means) and data storytelling**
